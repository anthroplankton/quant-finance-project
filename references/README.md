# Reference Materials

This directory is for reference-material organization. Keep committed files here limited to documentation about how references are managed.

`references/local/` is reserved for local-only reference materials that help local tools read paper sources and related files. It is intentionally ignored by Git.

Do not commit paper `.tex` source files, downloaded PDFs, publisher source archives, copied figures, or full paper text.

Commit only original reading notes, architecture summaries, implementation notes, and citation metadata. The recommended location for paper notes is `docs/papers/`.
